# TintolMarket 🍷

## Project Overview

TintolMarket is a project developed during the Bachelor's Degree in Computer Engineering in 2023.  
The main goal of this project was to develop a wine shop system.

The project was divided into two main phases:

- **Phase 1:**  
  Development of the core functionalities of the service, resulting in a functional web application, but without security mechanisms.

- **Phase 2:**  
  Implementation of security aspects to ensure that all interactions and the system itself were safe.

## Technologies Used

- Java  
- Gradle  

## Project Structure

The repository contains the source code of the TintolMarket system developed during the course unit project.
